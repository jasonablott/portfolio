Detailed Description

Expr class: a class representing a generic expression. See details for expression grammar. An expression can be a number, variable, or combination of those with a mathematical operator * or +.

  • The abstract grammar of Expr is: <expr> = <number> | <expr> + <expr> | <expr> * <expr> | <variable>
